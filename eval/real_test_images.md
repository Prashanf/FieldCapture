# Real Test Images Dataset

All 12 real-world evaluation photographs below are sourced from the **U.S. EPA Mold Image Library** (public domain, US Government work) and stored under `app/src/androidTest/assets/eval_images/`.

- **Library Source:** <https://epa.gov/mold/mold-image-library>
- **Download Status:** All 12/12 images downloaded cleanly (`HTTP 200`, valid JPEG).
- **Nameplate Note:** Public-domain stock nameplate photographs are not available from the library; nameplate pipeline verification uses synthetic `Canvas`/`Paint` images generated by `SyntheticNameplateGenerator`.
